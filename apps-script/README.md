# PG イベント登録ページ（Google Apps Script）

スプレッドシートの「イベント」に、改行つきでイベントを登録・編集するための専用ページです。
保存した内容は、HPとDiscordの告知（NANA Support）にそのまま反映されます。

- 保存できるのは、**このスプレッドシートを編集できる人だけ**です（ほかの人がURLを開いても保存できません）
- 「募集開始」「募集締切」の列は式で自動入力なので、このページからは書き換えません
- 使うのは無料です

## 最初の準備（1回だけ・5分くらい）

1. スプレッドシートを開いて、上のメニューの **拡張機能 → Apps Script**
2. 左の「ファイル」にある `コード.gs`（または `Code.gs`）を開き、中身を全部消して、このフォルダの **`Code.gs` の中身を貼り付け**
3. 「ファイル」の横の **＋ → HTML** を押し、名前を **`Index`** にして作成。中身を全部消して、このフォルダの **`Index.html` の中身を貼り付け**
4. 上の 💾（保存）を押す
5. 右上の **デプロイ → 新しいデプロイ**
   - 歯車 ⚙ → 種類は **ウェブアプリ**
   - 次のユーザーとして実行：**ウェブアプリにアクセスしているユーザー**
   - アクセスできるユーザー：**Google アカウントを持つ全員**
   - **デプロイ** を押す
6. 「アクセスを承認」→ 自分のGoogleアカウントを選ぶ
   - 「このアプリは Google で確認されていません」と出たら、**詳細 → （安全ではないページ）に移動** → **許可**
   - 自分で作ったページなので大丈夫です
7. 表示された **ウェブアプリのURL** をコピー。これが登録ページです

## 使いかた

- URLをブックマークしておく。もう1人の責任者にも同じURLを渡します（その人も最初の1回だけ「承認」が出ます）
- NANA Support の `/設定` →「📢 PG告知の設定」→「📝 登録ページのURL」に貼ると、`/設定` に登録ページを開くボタンが出ます（admin だけ）

## プログラムを更新したとき

`Code.gs` や `Index.html` を貼り直したら、**デプロイ → デプロイを管理 → ✏ 編集 → バージョン「新バージョン」→ デプロイ**。URLは変わりません。

## うまくいかないとき

- 「このシートを編集する権限がありません」：その人のGoogleアカウントを、スプレッドシートの共有で **編集者** にしてください
- 「見出しが見つかりません」：「イベント」シートの2行目の見出しの名前が変わっていないか確認してください
