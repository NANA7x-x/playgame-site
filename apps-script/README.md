# PG イベント登録ページ（Google Apps Script）

スプレッドシートの「イベント」に、改行つきでイベントを登録・編集するための専用ページです。
保存した内容は、HPとDiscordの告知（NANA Support）にそのまま反映されます。

- 保存できるのは、**このスプレッドシートを編集できる人だけ**です（ほかの人がURLを開いても保存できません）
- 「募集開始」「募集締切」の列は式で自動入力なので、このページからは書き換えません
- 使うのは無料です

## 最初の準備（1回だけ）

貼り付けるのは **`Code.gs` 1つだけ** です（画面の部分も中に入っています）。

1. スプレッドシートの **拡張機能 → Apps Script**
2. `コード.gs` の中身を全部消して、[Code.gs の中身](https://raw.githubusercontent.com/NANA7x-x/playgame-site/main/apps-script/Code.gs) を貼り付け → 💾 保存
3. 右上の **デプロイ → 新しいデプロイ** → 種類 **ウェブアプリ** → 実行するユーザー **ウェブアプリにアクセスしているユーザー** → アクセスできるユーザー **Google アカウントを持つ全員** → **デプロイ**
4. 承認（「確認されていません」と出たら **詳細 → 移動 → 許可**）
5. 出てきた **ウェブアプリのURL** が登録ページです

`Index.html` は画面を直すときの元ファイルです。Apps Script に入れる必要はありません（入っていても問題ありません）。

## 使いかた

- URLをブックマークしておく。もう1人の責任者にも同じURLを渡します（その人も最初の1回だけ「承認」が出ます）
- NANA Support の `/設定` →「📢 PG告知の設定」→「📝 登録ページのURL」に貼ると、`/設定` に登録ページを開くボタンが出ます（admin だけ）

## プログラムを更新したとき

`Code.gs` を貼り直したら、**デプロイ → デプロイを管理 → ✏ 編集 → バージョン「新バージョン」→ デプロイ**。URLは変わりません。

## うまくいかないとき

- 「このシートを編集する権限がありません」：その人のGoogleアカウントを、スプレッドシートの共有で **編集者** にしてください
- 「見出しが見つかりません」：「イベント」シートの2行目の見出しの名前が変わっていないか確認してください
