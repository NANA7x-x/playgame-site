# PG 参加記録の受け口（Google Apps Script）

NANA Support が記録した「だれがどのイベントに出席・欠席したか」を、スプレッドシートに書き込むための小さなプログラムです。
イベントが終わると自動で送られてきて、次の2つのタブができます。

- **参加記録**：1人1イベント1日1行（日付・イベント名・名前・申込済/申込なし・チーム・VCにいた分数・チェックイン・出席/欠席）
- **参加回数**：人ごとの出席回数・欠席回数、イベントごとの出席人数（自動で数えます）

同じイベントを何回送っても、その日の行が入れかわるだけで増えません。

## 最初の準備（1回だけ）

イベント登録ページとは **別のプロジェクト** にします。

1. https://script.google.com を開いて **新しいプロジェクト**（名前は「PG 参加記録」など）
2. `コード.gs` の中身を全部消して、[Code.gs の中身](https://raw.githubusercontent.com/NANA7x-x/playgame-site/main/apps-script/attendance/Code.gs) を貼り付け → 💾 保存 → 上の関数を `setup` にして ▶ 実行（スプレッドシートを使う許可が出るので許可する）
3. **デプロイ → 新しいデプロイ** → 種類 **ウェブアプリ** → 実行するユーザー **自分** → アクセスできるユーザー **全員** → **デプロイ**
4. 承認（「確認されていません」と出たら **詳細 → 移動 → 許可**）
5. 出てきた **ウェブアプリのURL** をコピー
6. Discord で `/設定` →「📢 PG告知の設定」→「✅ 参加記録」→「📊 スプレッドシート連携」に URL を貼る
7. BOT が **合言葉** を出すので、Code.gs の `const SECRET = 'ここに合言葉';` の `ここに合言葉` をそれに書きかえて保存
8. **デプロイ → デプロイを管理 → ✏ 編集 → バージョン「新バージョン」→ デプロイ**（URLは変わりません）
9. もう一度「📊 スプレッドシート連携」→ そのまま送信すると「✅ つながりました！」と出ればOK

## うまくいかないとき

- 「合言葉が違います」：手順7〜8（SECRET を書きかえて新バージョンでデプロイ）をもう一度
- 「つながりませんでした」：アクセスできるユーザーが **全員** になっているか確認
- 送り直したいとき：「✅ 参加記録」→「📤 いまシートに送る」（終わったイベントを全部送り直します）
