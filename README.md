# PLAY GAME 公式サイト

GitHub Pages で公開している PLAY GAME（PG）の公式サイトです。

## 更新のしかた

イベント・お知らせ・過去のイベントは Google スプレッドシートから読み込みます。
シートを書き換えると、サイトを開いたときに自動で反映されます。

- シートのID は `data.js` の `sheet.id` に設定します
- シートは「リンクを知っている全員：閲覧者」で共有してください
- シート名（イベント／お知らせ／過去のイベント）と1行目の見出しは変えないでください

紹介文・タグ・リンク（Discord / X）は `data.js` に書いてあります。
